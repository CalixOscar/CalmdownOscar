How I work

A multi-agent software engineering methodology: voice ideation → feasibility benchmarks → pre-mortem analysis → backend architecture → UI/UX mockups → security audits & post-mortems.

01 · Voice Capture & Vault Ingestion

Ideas get spoken into the Unli Rice iOS app, transcribed to markdown, and synced to the local vault — the same ground-truth memory every connected MCP agent reads from, so no tool starts a session cold.

02 · Feasibility & Market Research

Gemini Spark reads the raw vault text, checks technical feasibility, and benchmarks existing solutions to see whether the idea solves a real gap before any code gets written.

03 · Pre-Mortem & Handoff

Claude does the hard-reasoning work: a pre-mortem for likely failure modes, plus the guardrails and context rules that follow from it. It then writes a handoff — task, approach, files to touch, gotchas — for Codex to execute against, and checks the result on return rather than re-deriving the approach itself.

04 · UI Assembly & Security Audit

Antigravity produces a first-pass UI (via Figma over MCP) that Claude and Codex then build out properly — it's a starting point, not a finished frontend on its own. Near release, Claude runs a security audit on exploit vectors and encryption, Codex does a post-mortem, and the app ships through the relay to the App Store. Afterward, Unli Disk clears simulators and dead-end repos off my own machine.

Guardrails

The rules every app is built under.

They are written down once and read by every person and AI tool that works on the code. Where a script checks a rule on every commit, it says so; the rest are checked in review.

For the people using it

  • Put the phone down

    An app succeeds when you finish what you came to do and leave. No streaks, infinite feeds, notification spam or urgency bait.

  • Pay once, share with family

    Paid features are one-time purchases — Unli Disk, and Pro in ClearSpace, Shuttle Vision and Kitchen Vision — with Family Sharing switched on where the App Store allows it. No ads, and no third-party analytics or trackers.

    The exception: Wedding Concierge

    Every concierge answer runs on a paid AI service, so it has a subscription to cover that running cost.

  • Ask for a rating only after a real success

    Apple’s own prompt, never in the first session, and never a filter that steers unhappy users away from the store.

For their data

  • Keep data close

    On the device first; a server only where the job needs one. See where each app’s data goes.

  • No secrets in the app or the repository

    API keys live on a server relay, never inside an app.

    A script scans every commit
  • The server checks every request

    Hidden buttons aren’t security. A request has to prove it owns the record it asks for, and anything uncertain is refused.

  • Trust Apple’s receipt, not the app

    A purchase counts when Apple’s signed transaction says so, not when the app claims it.

For the work itself

  • Plan risky work before code

    Servers, payments, stored data, AI features and new dependencies get an intent document, a plan and a pre-mortem first.

    A script checks where plans are filed
  • “Success” isn’t evidence

    No tool’s report counts until the diff and a real build or test run agree.

  • Use the smallest tool

    If a hash and a blur score do the job, no model is called.

  • Open where others can teach me

    Unli Rice and OpenGrail are open source, because I want to learn from the people who read the code.

Rules guide the work; they don’t guarantee it. When an app falls short of one, the app changes — as ClearSpace did.

Continuous improvement · ClearSpace

From React Native to Swift, and still going.

ClearSpace started as a cross-platform app. Rebuilding it natively was the price of keeping the rules, and every release since has fixed something real.

  1. Version 1.0October 2025

    A React Native first version

    The first ClearSpace shipped as a React Native app, sold with monthly and annual subscriptions — against the studio’s own rule.

    • React Native
    • Broke a rule: subscriptions
    ClearSpace 1.0React Native · subscriptions · iOS 14 and later

  2. The rebuildJuly 2026

    Start again, natively

    The React Native code couldn’t be carried forward, so ClearSpace was rebuilt from scratch in Swift and SwiftUI on Apple’s PhotoKit — around one photo engine it now shares with Unli Disk on the Mac.

    • Swift
    • SwiftUI
    • PhotoKit
    • One engine, two apps
    React Native→Swift · SwiftUISame App Store listing, new code underneath

  3. Version 1.1August 2026

    The native app replaces the old one

    The Swift version took over the same App Store listing, and everything it clears goes to Apple Photos’ own Recently Deleted. The subscriptions are gone: today, reviewing and deleting one at a time is free, and bulk clearing is a single $9.99 purchase, shareable with family.

    • Rule kept: pay once
    • Native grid
    • Recently Deleted, not a hard delete

  4. Version 1.3September 2026

    Room to look properly

    On iPad, or an iPhone held sideways, a tapped photo opens beside the grid so you never lose your place. Photos stored in iCloud open sharp straight away, and purchases retry when the App Store is slow, with a visible button to try again.

    • iPad split view
    • Sharper iCloud photos
    • Sturdier purchases

  5. NextIn testing

    One purchase across Mac and iPhone, automatically

    Buying Unli Disk already includes ClearSpace Pro, but today that means emailing for a code. The automatic unlock is being tested, and it ships when it works on real accounts, not before.

Every app

The same loop, for every app.

None of the apps is finished. Each one sits somewhere in this loop, and goes round again.

  1. Ship an honest first version

    The smallest thing that does the job, described exactly as it is.

  2. Use it on real life

    ClearSpace began with my own 40,000-photo library, Unli Disk with my own Mac.

  3. Write down what falls short

    Gaps become to-dos in Unli Rice, so the next session starts from them.

  4. Fix it within the rules

    Even when that means starting again, as ClearSpace did.

Each app’s own changes — what was tried, kept and cut — are under “How it’s built” on the apps page.

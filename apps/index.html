The pipeline
How I work

The diagram above isn't decoration — it's genuinely how everything here, including this website, gets made. Different tools at every step, all pointed at one goal: to bring an idea to life.

One pipeline, every time

Every idea travels the same road: brainstormed into a prompt, specced out, planned, built, pushed to GitHub, and shipped. Tools get swapped as better ones appear, but the road never changes — so no project ever depends on any single tool staying the best.

Each tool has one job

Gemini turns a rough idea into a proper prompt. Claude does the careful thinking — architecture, plans, reviewing the work. Codex and Antigravity write most of the actual code. Nobody does everything; splitting the work this way is what gets things finished.

One shared memory

The Obsidian vault in the middle of the diagram is what holds it together: plain text notes on my own computer — what's decided, what's next, where I left off. Every tool reads it before starting and updates it when done, so I never re-explain anything, and switching tools mid-task costs nothing.

Built between naps

All of this runs on borrowed time — the gaps between changing diapers and Oscar's naps. That's exactly why the pipeline exists: I can put work down mid-thought, and days later any tool can pick up the thread right where it was left. The goal from here is to hand off more and steer less — walk away, come back to see it finished.

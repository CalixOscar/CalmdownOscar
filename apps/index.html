Wedding Concierge

macOS iOS Vercel Proxy CloudKit Local MLX Evals

Multi-platform conversational AI planning companion engineered with a secure Vercel API proxy wall, CloudKit cross-device sync, and structured spatial planning tools.

01 · Problem

Planning Decision Fatigue

02 · Architecture & Protocols

03 · Impact

Delivers enterprise-grade conversational AI planning with real-time venue search, zero user database tracking, and seamless multi-device sync.

Unli Rice

macOS iOS MCP Protocol Multi-LLM State Open Source

Open-source persistent memory layer for multi-agent LLM systems over Model Context Protocol (MCP) with on-the-go iOS voice-to-vault synchronization.

01 · Problem

Context Drift & Token Waste

Building complex apps with multiple LLM engines (Gemini, Claude, Codex, Antigravity) causes rapid context window ballooning, expensive token consumption, and hallucination loops when starting fresh sessions. Standard note systems become unorganized bloatware during multi-agent handoffs.

02 · Architecture & Protocols

MCP Protocol & Shared Vault

Engineered an open-source persistent memory layer using Model Context Protocol (MCP) and file-system state synchronization. Connects disparate LLMs to a single ground-truth vault featuring explicit guardrails, evaluation rules, and non-destructive folder governance. Includes an iOS voice-capture app that syncs raw audio notes to macOS for instant agent retrieval.

03 · Impact

Zero Re-explanation Friction

Eliminates context re-explanation across multi-agent chat sessions, enforcing strict architectural consistency and zero-friction model swapping without loss of project memory.

The pipeline
How I work

The diagram above isn't decoration — it's genuinely how everything here, including this website, gets made. Different tools at every step, all pointed at one goal: to bring an idea to life.

Structured CI/CD pipeline

Every project follows an architected workflow: brainstormed into structured prompts, specced out, planned, built, pushed to GitHub, and deployed. Tools are decoupled, ensuring no single AI model creates a vendor lock-in or architectural bottleneck.

Specialized multi-agent roles

Gemini initiates early-stage ideation. Claude conducts deep reasoning, system architecture, and code reviews. Codex and Antigravity handle high-velocity code execution and UI assembly. Each tool performs its optimal role with automated handoffs.

MCP persistent state layer

Unli Rice acts as the central ground truth: a persistent memory layer operating over Model Context Protocol (MCP). Every AI agent reads project decisions and updates the state on completion, eliminating context drift and re-explanation friction.

Asynchronous execution model

Engineered for high efficiency across fragmented time windows. Structured handoffs and file-system guardrails allow complex engineering tasks to pause safely mid-thought and resume asynchronously without losing state.
